# Laboratory 01 — Welcome to the Cloud

## Mission Overview
This mission introduced the cloud-based Linux environment using KillerCoda.
I learned to navigate Linux, gather system information, organize files,
and set up a professional GitHub portfolio.

## Objectives
- Access Linux via KillerCoda
- Explore the OS and gather system details
- Organize files and directories
- Create and maintain a GitHub repository
- Document work using Markdown

## Activities Performed
1. Launched Ubuntu 24.04 on KillerCoda
2. Created a new user account and logged in
3. Retrieved system specifications
4. Built a workspace folder structure
5. Created GitHub portfolio repository
6. Wrote documentation in Markdown

```bash
useradd       # Create new user
passwd        # Set password
su            # Switch user
whoami        # Show current user
pwd           # Show working directory
hostname      # Show system name
lsb_release   # Show distro info
uname         # Show kernel version
lscpu         # Show CPU info
free          # Show memory
df            # Show disk usage
mkdir         # Create directories
nano          # Edit files
