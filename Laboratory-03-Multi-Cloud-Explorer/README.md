# Cloud Provider Research Project

This project explores and compares the three major public cloud platforms — **Amazon Web Services (AWS)**, **Microsoft Azure**, and **Google Cloud Platform (GCP)**. Each provider is researched individually, compared side-by-side, and summarized with recommendations and personal reflection.

---

## Project Contents

| File | Description |
|---|---|
| `aws-research.md` | AWS overview, infrastructure, services, advantages, and use cases |
| `azure-research.md` | Azure overview, infrastructure, services, advantages, and use cases |
| `gcp-research.md` | GCP overview, infrastructure, services, advantages, and use cases |
| `cloud-platform-comparison.md` | Side-by-side comparison of all three providers |
| `client-recommendations.md` | Recommendations for different types of clients and needs |
| `reflection.md` | Personal reflection on what was learned |
| `screenshots/` folder | Homepage and console screenshots for each cloud provider |

---

## Research Structure

Each provider research file includes:
- **Brief Overview** — Introduction and background
- **Global Infrastructure** — Regions, availability zones, and network presence
- **Cloud Management Console** — Official console URL and interface
- **Four Core Services** — Compute, Storage, Networking, and Database
- **Three Advantages** — Key strengths and differentiators
- **Typical Enterprise Use Cases** — Common real-world applications
- **References** — Links to official sources

---

## Summary

| Provider | Key Strength |
|---|---|
| **AWS** | Most established, broadest service range, largest community |
| **Azure** | Seamless Microsoft integration, strong hybrid enterprise support |
| **GCP** | Global high-performance network, leadership in data, AI, and sustainability |

All information was gathered from official provider websites and organized into consistent formats for easy comparison and reference.
